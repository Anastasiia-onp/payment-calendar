## Структура проекта

```
payment-calendar/
├── 01_input/        исходный реестр обязательств (только чтение)
├── 02_calc/         Excel-календарь с формулами
├── 03_output/       выводы и управленческие решения (.md)
├── 04_dashboard/    интерактивный HTML-дашборд — интерфейс проекта
├── scripts/         Python-код:
│                      make_template.py     — форма реестра
│                      expand_recurring.py  — разворот правил повтора
│                      import_registry.py   — импорт из выгрузок
│                      make_sample_export.py — тестовая выгрузка
├── README.md        инструкция запуска (этап 9)
└── SKILL.md         скилл для коллег (этап 9)
```

Имена папок английские — рекомендация курса, защита от сбоев кодировки в Windows-консоли. Логика стадий сохранена: исходные → расчёты → выводы → подача.

## Проверки на каждом этапе

1. Исходный файл не изменён — сверка размера и даты изменения.
2. Итог Excel = итог Python до копейки.
3. Сумма по строкам = сумма по столбцам в календаре.
4. Остаток на конец недели N = остаток на начало недели N+1.
5. Нет выдуманных цифр: каждая сумма прослеживается до строки реестра.
6. Дашборд после пересчёта в браузере показывает те же цифры, что Excel.

## Демонстрация

**Локально:** Excel + HTML-дашборд, скриншоты каждого шага.

**Публикация:** дашборд публикуется как артефакт Claude — рабочая ссылка, которую можно открыть и покликать. Виртуальный сервер не нужен. Код — в репозитории GitHub.

Условие: перед публикацией данные обезличиваются — контрагенты заменяются на «Подрядчик 1», «Заказчик 2». Суммы остаются реальными.
