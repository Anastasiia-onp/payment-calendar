# Публикация проекта на GitHub

Репозиторий уже создан локально, проект закоммичен. Осталось завести аккаунт
и отправить код на GitHub. Примерно 15 минут.

---

## 1. Создать аккаунт

1. Открыть [github.com/signup](https://github.com/signup).
2. Ввести почту, придумать пароль и имя пользователя.
   Имя пользователя попадёт в ссылку на проект: `github.com/<имя>/payment-calendar`.
   Лучше что-то нейтральное и профессиональное — ссылку можно класть в резюме.
3. Подтвердить почту по письму.

## 2. Создать репозиторий

1. Нажать **+** в правом верхнем углу → **New repository**.
2. Заполнить:
   - **Repository name**: `payment-calendar`
   - **Description**: `Прогноз денежных средств на 13 недель с поиском кассовых разрывов`
   - **Public** — чтобы проект можно было показать работодателю
   - **НЕ** ставить галочки «Add a README», «Add .gitignore», «Choose a license» —
     они уже есть в проекте и помешают первой выгрузке
3. **Create repository**.

## 3. Отправить код

GitHub покажет страницу с командами. Нужен блок
«…or push an existing repository from the command line».

Выполнить в Claude Code, подставив своё имя пользователя
(символ `!` в начале строки выполняет команду прямо в чате):

```bash
cd "C:/Users/vipma/pa-finance/payment-calendar"
git remote add origin https://github.com/<имя-пользователя>/payment-calendar.git
git branch -M main
git push -u origin main
```

При первой выгрузке откроется окно входа в GitHub — войти под своим аккаунтом.
Если окно не появилось и в терминале просят пароль: вместо пароля нужен токен,
см. раздел ниже.

## 4. Проверить

Открыть `github.com/<имя-пользователя>/payment-calendar`.

Должно быть видно:
- README с описанием и ссылкой на дашборд;
- папки `01_input` и `scripts`;
- один коммит.

Ссылку на этот репозиторий сдавать как итоговый проект.

---

## Если просят пароль в терминале

GitHub не принимает пароль от аккаунта при выгрузке кода — нужен токен.

1. [github.com/settings/tokens](https://github.com/settings/tokens) →
   **Generate new token** → **Generate new token (classic)**.
2. **Note**: `payment-calendar`, **Expiration**: 90 days.
3. Отметить галочку **repo**.
4. **Generate token** — скопировать строку, она показывается один раз.
5. Когда терминал спросит пароль — вставить токен.

## Как потом обновлять проект

После любых изменений:

```bash
cd "C:/Users/vipma/pa-finance/payment-calendar"
git add -A
git commit -m "Что изменилось"
git push
```
